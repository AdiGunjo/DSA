Linear Search
Linear search is the simplest searching technique, checking each element in a list sequentially from the beginning until the target value is found or the list ends. It requires no particular ordering of data, making it usable on any dataset, sorted or unsorted. Its simplicity makes it easy to implement and understand, but it becomes inefficient for large datasets since, in the worst case, every element must be examined. Time complexity is O(n), meaning search time grows linearly with the size of the input. It's best suited for small lists or one-time searches where preprocessing (like sorting) isn't worthwhile.

Binary Search
Binary search is a highly efficient algorithm for finding an element in a sorted array by repeatedly dividing the search interval in half. It compares the target value to the middle element; if they don't match, the half in which the target cannot lie is eliminated, and the search continues on the remaining half. This process repeats until the value is found or the interval is empty. Its major requirement is that the data must already be sorted. With a time complexity of O(log n), it dramatically outperforms linear search on large datasets, making it ideal for frequent lookups.

Bubble Sort
Bubble sort is a straightforward comparison-based sorting algorithm that repeatedly steps through the list, comparing adjacent elements and swapping them if they're in the wrong order. With each pass, the largest unsorted element "bubbles up" to its correct position at the end of the list. This continues until no swaps are needed, indicating the list is sorted. While easy to understand and implement, it's inefficient for large datasets due to its O(n²) time complexity in the average and worst cases. An optimization can stop early if no swaps occur in a pass, giving O(n) performance on already-sorted data.

Insertion Sort
Insertion sort builds the final sorted array one element at a time by taking each element from the unsorted portion and inserting it into its correct position within the already-sorted portion. It works similarly to how one might sort playing cards in hand. Although its worst-case and average time complexity is O(n²), it performs efficiently on small or nearly-sorted datasets, achieving O(n) in the best case. It's a stable, in-place sorting algorithm requiring minimal extra memory. Its simplicity and adaptability to partially sorted data make it a practical choice for small lists or as part of hybrid algorithms.

Selection Sort
Selection sort works by repeatedly finding the minimum (or maximum) element from the unsorted portion of the list and swapping it with the first unsorted element, gradually building a sorted section from left to right. Unlike insertion sort, it doesn't adapt to existing order in the data — it always performs the same number of comparisons regardless of initial arrangement, giving it a consistent O(n²) time complexity in all cases. It is simple to implement and performs a minimal number of swaps compared to other O(n²) algorithms, though it is not a stable sort and is inefficient for large datasets.

Quick Sort
Quick sort is a highly efficient, divide-and-conquer sorting algorithm that selects a "pivot" element and partitions the array so that smaller elements move to its left and larger elements to its right. It then recursively applies the same process to each partition until the entire array is sorted. On average, it achieves excellent performance with O(n log n) time complexity, making it one of the fastest general-purpose sorting algorithms in practice. However, its worst-case complexity is O(n²), which can occur with poor pivot choices on already-sorted data. It's widely used due to its speed and in-place, low-memory-overhead sorting.

Shell Sort
Shell sort is an optimized extension of insertion sort designed to overcome its limitations with large lists. Instead of comparing only adjacent elements, it starts by comparing elements that are far apart (defined by a "gap" value), gradually reducing the gap until it becomes 1, at which point it functions as a standard insertion sort. This approach allows elements to move closer to their final position more quickly, reducing the total number of shifts needed. Its time complexity ranges from O(n log n) to O(n²) depending on the gap sequence chosen, making it notably faster than basic insertion sort on larger datasets.
